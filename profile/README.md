# Cascatelle

> 像小瀑布一样，一件作品接着一件作品。

Cascatelle 是一个专注 **Minecraft 基岩版（Bedrock Edition）** 内容创作的组织。

## 我们在做什么

| 方向 | 说明 |
| --- | --- |
| 服务器plugin LL&endstone plugin | 注重服务器插件开发 |
| 客户端mod llmods | 客户端mod开发 |
| 附加包 Add-on | 实体、物品、方块与行为逻辑，遵循基岩版原生组件体系 |
| 资源包 Resource Pack | 材质、模型、界面与音效 |

## 参与贡献

欢迎任何形式的参与：反馈问题、提交改进、补充文档、分享使用体验。
